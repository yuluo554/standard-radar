# 10-16-standard-radar 项目计划总览

**项目**：标准变更雷达（GB 国标 / HB 行标 双源抓取 + 统一 schema + 快照 diff 变更检测 + 标准号版本解析 + 状态迁移与"即将实施"倒计时 + 关键词订阅与中文日报；纯本地 Python CLI + 本地报告）
**方法论**：ai-tool-project-sprint（数据先行 + 双源适配器失败隔离 + 持久快照字段级 diff + 真值基准 + 纯本地交付）
**项目系列**：同系列题（不参赛，发 GitHub 公开仓库）
**命名约定**：本地目录 `10-16-standard-radar`（`10-16` = 2026-10-16 日期标签）；**GitHub 仓库名 = `standard-radar`（纯净名，去日期前缀）**，沿用系列惯例 `yuluo554/<kebab-name>`；署名 `yuluo554`。
**定位宣言（v1）**：本地定时抓取全国标准信息公共服务平台，把"新发布 / 即将实施 / 即将被代替"的国标与行标变成一份每日中文提醒——快照 diff 检测变更，不是每次全量翻页。企业合规、研发、质量、采购、投标都必须跟标准，人工翻官网极易漏。

## 里程碑依赖与验收要点

- **M1 门禁**：接口实测留档（含 HTTP 状态、耗时、原始 JSON 片段）+ 真值台账就位，方可进 M2；未挂原文核对的字段不得进入后续落库路径。
- **M3 门禁**：diff 判定须在预置快照对上复现标注真值（检出率/误报率有数），且标准号归并结论可由字符串复算。
- **M6 门禁**：`data/README.md` 局限登记与题面口径一致；无遥测、无标准全文下载的合规声明随仓库发布。
