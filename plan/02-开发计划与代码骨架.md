## 一、需求 → 能力转译

题面三条痛点（plan/01 §一）逐一转译为确定性能力，防止"做完发现没解决原问题"：

| # | 用户痛点 | 能力转译（本项目做什么） | 落点模块 | 里程碑 |
|---|---|---|---|---|
| 1 | 翻不过来：GB 8 万级 / HB 12 万级，接口无日期区间参数 | ①快照 diff：只报"两轮之间变了的"，不必全量翻页再人工对；②本地关键词过滤：把"我这行关心的"从变更流里筛出来；③首期不依赖服务端搜索，结果可复现 | 快照+diff / 订阅+日报 | M3 / M4 |

| 3 | 倒计时无人提醒：实施日期到了才知道 | 基于 `ACT_DATE` 原文的"即将实施"剩余天数预警（缺日期不生成，绝不臆测） | 倒计时 | M3 / M4 |
| 4 | （信任底座）启发式结果不可信、无法回溯 | 未挂原文核对不落库：raw 留证 + `pending` 纪律 + 预置快照对真值基准 | 全链路 | M1 / M4 |

## 三、开发顺序与依赖

```
M1 数据先行 ──► M2 抓取 ──► M3 快照/diff/解析 ──► M4 基准/订阅/日报 ──► M5 交付 ──► M6 发布
      │              │                │
      │              └─ 依赖 M1 字段核对结论（统一 schema 冻结）
      └─ 预置快照对（合成数据）不依赖活网 → M3 的 diff 校验可独立起步
```

- M2（抓取）依赖 M1 的字段核对结论；
- M3 的 diff/版本/状态校验建立在 M1 的**合成预置快照对**上，不依赖 M2 活网结果（保证可复现、可离线）；
- M4 依赖 M3 的事件模型；M5 依赖全部模块；M6 只做发布动作（脱敏/建仓/CI/tag/Release）。

## 五、骨架期桩策略与转正约定

- 未到交付里程碑的 CLI 子命令为**显式桩**：打印"尚未实现 + 目标里程碑"并 `exit 3`——不是静默失败、不是假成功（退出码契约见 plan/03 §七）；
- `tests/test_cli_contract.py` 的 `STUBS` 表登记全部桩命令（命令 → 目标里程碑）；
- **命令转正时**：从 `STUBS` 移除该项 + 补该命令自身的**离线**用例（不访问网络），并回写本文 §七 状态列；
- 模块桩转正时：保留 docstring 中的纪律条目为准绳；实现不得绕过 `models.py` 的统一 schema（除非同步修订 schema 并回写 plan/04 冻结记录）。

## 六、统一 schema 字段（**已冻结 v1**；M1 2026-10-15 按 400 条真实捕获核对，无出入 → 字段集与草案 v0 一致，逐字段来源落定）

`StandardEntry`（src/standard_radar/models.py）：

| 字段 | 含义 | 来源（实测字段名） | 缺失时 |
|---|---|---|---|
| `std_id` | 平台条目 id | GB/HB：`id` | 整条跳过并记录（不落库） |
| `source_lib` | 库来源 | 取 `GB` / `HB` | — |
| `std_code` | 标准号原文 | `C_STD_CODE` | 整条跳过并记录 |
| `name_cn` | 中文名称原文 | `C_C_NAME` | 整条跳过并记录 |
| `nature` | 标准性质 | GB/HB：`STD_NATURE`（M1 实测两库均有：推荐性/强制性） | `pending` |
| `issue_date` | 发布日原文 | `ISSUE_DATE` | `pending` |
| `act_date` | 实施日原文 | `ACT_DATE` | `pending`（倒计时不生成） |
| `state` | 状态原文 | `STATE` | `pending` |
| `dept` | 归口或主管部门 | HB：`CHARGE_DEPT`（M1 实测必有）；**GB 无对应字段 → 恒 pending** | `pending` |
| `extra` | 适配器保留的其余原文字段（值统一转 str 落盘） | 各库不一致；HB 的 `C_STD_CODE2..5` 为同义写法变体（不入映射，留 extra 回溯） | 可空 |

纪律：字段值一律取接口**原文**；未返回或映射不出 → `None`，输出侧标 `pending`，不臆测、不做启发式补全；映射不出的**条目整条跳过并记录**（条目级跳过，不做部分补全）。

## 七、CLI 命令面（草案定稿）

```
standard-radar [--version] <命令> [选项]
```

| 命令 | 说明 | 选项（骨架期草案） | 状态 |
|---|---|---|---|
| `fetch` | 抓取 GB/HB 双库 → 原始 JSON 留证 + 归一化条目 | `--source {gb,hb,both}`、`--page-size`、`--max-pages` | 桩（M2） |
| `snapshot` | 本轮条目集持久化为快照轮次 | — | 桩（M3） |
| `diff` | 最近两轮快照的字段级 diff（新增/字段变更/消失） | — | 桩（M3） |
| `parse` | 解析标准号并给出版本序列 | 位置参数：一个或多个标准号 | 桩（M3） |
| `report` | 生成中文日报（Markdown/HTML） | `--format {md,html,both}`、`--out DIR`、`--subscriptions FILE` | 桩（M4） |
| `run` | 全链路一条命令：抓取 → 快照 → diff → 日报 | 汇合上述常用选项 | 桩（M5） |
| `selftest` | 环境自检（解释器/编码/store 可写） | — | ✅ 可用 |

公共选项（各子命令）：`--store DIR`（默认 `stdradar_store`）、`-v/--verbose`。退出码契约：`0` 成功 / `1` 运行失败 / `2` 用法错误 / `3` 功能未实现（骨架期）——详见 plan/03 §七。

## 八、开发工作流纪律（每棒照抄执行）

1. **一棒一对话**：一个里程碑 = 一个新对话；对话收尾**必须先落盘 `plan/HANDOFF-M<next>.md`**（六节：进度+证据 / 待办 / 既定口径 K 清单 / 环境坑 / DoD checklist / 命令速查）才能结束；
2. **收尾顺序固定**：DoD 验证 → plan/00·05·06 状态回写 → 写 HANDOFF → commit（有远端则 push 等 CI 绿）；
3. **诚实口径**：未推送 = 未跑 CI，一律写"本地等价校验（未接远端，CI 待首推验证）"并列出可指认的替代证据与缺口；
4. **双解释器**：测试/冒烟在 `py -3.8` 与 `py -3.12` 两条通道分别跑（本机已实测拥有两通道）；代码须过 3.8 底线语法；
5. **编码三通路加固**：入口 `ensure_utf8_stdio`（救用户）+ 子进程调用显式 `encoding=`（救一切环境）+ CI `PYTHONUTF8=1`（救 CI）；
6. **行尾与冻结**：源码/文档 LF（CR 守门测试）；`data/snapshots/**`、`data/fixtures/**` 为 `-text` 冻结半区（字节不可变，配 sha256 台账复算）；
7. **零网络于测试与基准**：单测/基准不访问网络；live 抓取仅手动执行并单独记录证据；
8. **确定性生成**：合成数据生成禁 stdlib `random`、禁 set 迭代序、禁系统时钟；产物配"再生成位级一致"守门；
9. **提交纪律**：前缀 `计划：/骨架：/数据：/抓取：/diff：/基准：/交付：/发布：/收尾：`；库内文档一律相对路径；
10. **守门要证伪**：新增/改写的守门测试做一次变异验证（故意弄坏被测行为 → 必须变红）。

## 九、本机开发环境（2026-10-15 实测）

| 项 | 实测结果 | 备注 |
|---|---|---|
| Python 通道 | `py -3.8`（3.8.8）+ `py -3.12`（3.12.10） | `python` 为商店占位符 → 一律用 `py` |
| pytest | 3.8 → 7.4.4；3.12 → 8.4.2 | 两条通道均可跑测试 |
| pip | 3.8 → 25.0.1；3.12 → 26.2.1 | 安装：`py -3.8 -m pip install -e ".[dev]"`（必要时 `--no-build-isolation`） |
| setuptools | 3.8 → 75.3.4；3.12 → 84.0.0 | 均满足 `>=61`（PEP 621） |
| git | 无 remote（建仓留 M6） | CI 文件就位但未跑 → "待首推验证" |
| 编码 | 统一起见脚本加 `-X utf8`；代码内守 `ensure_utf8_stdio` | 中文控制台 cp936 保持原生、放宽 errors |

常规命令：

```bash
py -3.8 -X utf8 -m pytest            # 底线解释器全量测试
py -3.12 -X utf8 -m pytest           # 3.12 通道全量测试
py -3.8 -X utf8 -m standard_radar --version
py -3.8 -X utf8 -m standard_radar selftest
```

pip 备用通道（注册表系统代理污染时）：`NO_PROXY="*" no_proxy="*" py -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <pkg>`
