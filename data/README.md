## 四、合成数据纪律

1. **真值基准**：使用**预置快照对 + 植入真值**——构造"同一批标准的两轮快照"受控样本，人工标注哪些条目应判为"新增"、哪些应判为"状态迁移"，标注对象为公开接口字段（`std_id`/`STATE`/`ACT_DATE`/`ISSUE_DATE`），每条标注附 `std_id` 可回溯；
2. **合成样例**：合成样例的标准号**一律使用真实格式**（如 `GB/T XXXXX-YYYY`、`MH/T XXXX—YYYY` 占位），并**标注为快照样本**；不得虚构真实标准号/名称/日期的对应关系；
3. **禁止事项**：不得把推断值冒充标注真值；不得虚构真实标准的发布日期/实施日期；不得凭标准名称臆测其状态或版本关系；
4. **缓存边界**：仅缓存标准**元数据**（标准号/名称/状态/日期/归口），不下载标准全文、不镜像详情页整页。

## 五、数值口径纪律

- **一处定义**：接口总量（GB `79826` / HB `119169`）、关键词命中数（`人工智能` GB 114 / HB 113）、耗时（0.20–0.47s）均为**基准日 2026-10-15 实测快照值**，随平台数据增长必然变化，**仅作数据源可获取性证据，不作交付承诺**；
- **不写漂移硬数字**：首期"**5 模块 / 2 库**"为**设计决策**，一处定义（`plan/01-题目文档.md` + `plan/00-README总览.md`），不做会漂移的测试类硬数字承诺；准确率/检出率等指标口径以真值基准 README 为准；
- **待获取项如实登记**：地方标准通道 `total=0`、`STATE` 过滤无效、无日期区间参数——均如实登记为局限，不粉饰。
